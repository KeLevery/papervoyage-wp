# 纸旅 PaperVoyage 更新日志

## 1.4.12（2026-09-25）

### 修复
- **阻断级**：修复首页大封面 100vw 破框全宽导致的 Windows 桌面浏览器横向滚动溢出；
- **阻断级**：修复首页“最新文章 More →”与全站筛选条“全部”按钮死循环跳回自身的问题（`get_permalink(0)` 漏洞）；
- **核心功能**：全面恢复后台自定义器“关于我页面”12 项数据配置，实现 Demo 同款 6 格数据徽章与社交小工具，同时兼顾 Gutenberg 多列排版；
- **页面切换**：修复 PJAX 站内切入文章页导致主导航栏所属栏目高亮完全熄灭的问题（同步服务端高亮状态）；
- **评论交互**：修复非文章页首屏进入文章页/留言墙点击回复评论报 `addComment` 未定义异常；
- **分类呈现**：消除杂文手稿卡片（`manuscript`）被统一随笔配置死锁的问题，清理重复 switch 分支，支持关闭统一卡片时按栏目呈现各自专属卡片；
- **描述解析**：优化分类与归档描述提取逻辑，杜绝单行中文被误判为英文小标，完整保留多段落简介；
- **交互细节**：修复点击“复制链接”按钮导致 SVG 图标永久丢失与重复点击文字锁死问题，增加防抖；
- **管理后台**：修复后台分类目录初次上传 Hero 图缺失“移除图片”按钮 DOM 的问题，并增加保存权限校验；
- **主题外观**：修复明暗主题切换时根元素背景色内联残留造成的色差闪烁；
- **无障碍与结构**：修复搜索表单 Label 与 Input ID 缺失；修正留言墙与时间线模板 `the_title()` 调用时序；
- **性能优化**：时间线归档页面消除 N+1 次全量数据库查询，大幅提升响应速度；
- **工程构建**：构建脚本 `build-theme-zip.ps1` 支持从 `style.css` 自动读取最新版本号。

## 1.4.8（2026-08-30）

### 修复
- **修复主题升级后页面无变化的缓存问题**：
  - 根因：`functions.php` 中 `PAPERVOYAGE_VERSION` 常量被写死为 `'1.4.0'`，导致 CSS/JS 的缓存版本号（`?ver=1.4.0`）从不随 `style.css` 的 `Version:` 字段更新；上传新主题后，浏览器与服务端缓存命中旧 URL，新样式无法生效；
  - 改为自动读取 `style.css` 头部 `Version` 字段（`wp_get_theme()->get('Version')`），此后每次改版本号即可自动失效旧缓存；
  - 本次同时承载 1.4.7 的首页大封面破框改动，升级后首页 Hero 应正确铺满浏览器全宽。

## 1.4.6（2026-08-29）

### 修复
- **修复「关于我」全宽模板右侧大片空白**：
  - 根因：主题未提供 `theme.json`，导致 Gutenberg 块预设类（`has-base-2-background-color`、`has-tertiary-color`、`has-medium-font-size`）与 `.wp-block-columns.alignwide` 的满宽约束失效，编辑器里用原生 Columns 块（60%/40%）排出的两栏无法铺满 1200px；
  - 新增关于页专属兼容补丁（仅作用于 `.about-page-content`，不影响其他页面）：强制 `.wp-block-columns.alignwide` 撑满 100% 宽度、按 `flex-basis` 正确分配左右栏；
  - 为卡片背景色（`has-base-2-background-color` → `--bg-secondary`）、标签/次要文字（`has-tertiary-color`/`has-secondary-color` → `--muted`）、中号字号（`has-medium-font-size`）提供主题变量回退，自动跟随明暗双主题；
  - 窄屏（≤1024px）两栏自动堆叠为一栏。

## 1.4.5（2026-08-29）

### 改进
- **彻底支持在 WordPress 编辑器中 100% 自由排版与自定义关于页**：
  - 移除此前模板中硬编码锁定正文与右侧卡片的逻辑，模板直接渲染 `the_content()`，用户在页面编辑器中打什么字、放什么块、改什么数据就显示什么，完全自由；
  - 放开单页 `72ch`（650px）的死锁限制，无论是普通页面（`page.php`）还是关于页模板，多栏布局（Columns）与全宽内容均自动撑满 **1200px**，**彻底消灭右侧 550px 大片空白**；
  - 编辑器中的两栏排版自动获得 48px 舒适间距与对齐，卡片文字与数字具备单行防折行保护，绝不再次出现折行断字；
  - 顶部 Hero 封面大图改为由「特色图片」智能触发（上传即显示 Demo 同款暗角大图，不上传则显示干净优雅标题），完全由用户自主掌控。

## 1.4.1（2026-08-26）

主题 zip 发布构建脚本 `build-theme-zip.ps1`（保证 zip 内为顶层 `papervoyage/` 目录结构）。

本版本聚焦「页面切换体验」，从整页跳转升级为无感切换。

### 新增
- **PJAX 无感切换**（`assets/js/pjax.js`）：点击站内链接/搜索表单不再整页刷新，
  仅替换主内容区，header/导航/footer 不重渲染，CSS/JS 零重载，全程无白屏。
  支持浏览器前进/后退（含滚动位置恢复）、内存缓存（上限 10 页）。
  失败自动回退整页跳转；主题定制器预览中自动停用；登录态不使用缓存。
- **帖子卡片瀑布进场**：栏目页/列表页卡片逐张上浮淡入（`card-in`）。
- **跨文档 View Transitions**：作为新标签页/降级场景下整页导航的平滑过渡（纯透明度交叉）。
- **Speculation Rules 悬停预取**：鼠标悬停链接即预取目标页 HTML，整页导航场景下近乎即时。
- **主题截图** `screenshot.png`（后台主题列表展示）。

### 修复
- `category.php` / `page-guestbook.php` 重复 `<main>` 标签（嵌套 main、重复 id、双份 padding）。
- `style.css` 栏目区块注释断裂导致 `.cat-albatross .cat-hero` 规则失效。
- CLS 布局跳动：字体改为 `display=optional` + preconnect（零换排）；
  `scrollbar-gutter: stable` 消除滚动条出现/消失的横向跳动；
  `pageswap` 时回顶对齐，消除过渡中的上下跳动；
  移除前台 twemoji 脚本；admin-bar 吸顶偏移修正；Hero 图 preload；兜底图补宽高。
- 白屏：`<head>` 内联脚本在 CSS 到达前先铺纸色底（明暗两套），文档初始绘制不再是浏览器白底。

### 调整
- 首页右栏标签区从胶囊容器改为「小节标题 + 纯文字标签流」，多标签自然换行。
- 导航/分享的复制链接改为事件委托，适配 PJAX 局部替换。
