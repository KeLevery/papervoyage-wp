# 纸旅 PaperVoyage 更新日志

## 1.4.2（2026-08-26）

### 新增
- **分类 Hero 图片上传**：分类目录新增/编辑页内置媒体库选择器（`functions.php`），
  可为每个栏目上传独立 Hero 大图；未上传时回退主题默认图 `hero-default.jpg`，视觉不缺席。
- **栏目风格拼音 slug 兼容**：中文分类使用拼音别名（`suibi` / `youji` / `yingshi` 等）时，
  自动映射到对应栏目的专属视觉风格。
- **导航英文副标题兜底**：菜单项未填「描述」时，按常用栏目名（首页/随笔/游记等）内置
  中文 → 英文映射，导航双语排版开箱即用。
- **Hero 区描述文字**：通用分类页 Hero 显示分类描述。

### 改进
- 评论表单全面重构：昵称/邮箱/站点三字段一行排布、placeholder 文案、必填标记、
  登录态提示条、Cookie 记住选项，样式由内联迁移至 CSS 类（`comments.php` / `style.css`）。

### 修复
- 导航当前高亮扩展至父级/祖先菜单项（在文章详情页也能点亮所属栏目）。
- 评论回复标题布局、`.no-comments` 样式由内联改为类。

## 1.4.1（2026-08-26）

主题 zip 发布构建脚本 `build-theme-zip.ps1`（保证 zip 内为顶层 `papervoyage/` 目录结构）。

本版本聚焦「页面切换体验」，从整页跳转升级为无感切换。

### 新增
- **PJAX 无感切换**（`assets/js/pjax.js`）：点击站内链接/搜索表单不再整页刷新，
  仅替换主内容区，header/导航/footer 不重渲染，CSS/JS 零重载，全程无白屏。
  支持浏览器前进/后退（含滚动位置恢复）、内存缓存（上限 10 页）。
  失败自动回退整页跳转；主题定制器预览中自动停用；登录态不使用缓存。
- **帖子卡片瀑布进场**：栏目页/列表页卡片逐张上浮淡入（`card-in`）。
- **跨文档 View Transitions**：作为新标签页/降级场景下整页导航的平滑过渡（纯透明度交叉）。
- **Speculation Rules 悬停预取**：鼠标悬停链接即预取目标页 HTML，整页导航场景下近乎即时。
- **主题截图** `screenshot.png`（后台主题列表展示）。

### 修复
- `category.php` / `page-guestbook.php` 重复 `<main>` 标签（嵌套 main、重复 id、双份 padding）。
- `style.css` 栏目区块注释断裂导致 `.cat-albatross .cat-hero` 规则失效。
- CLS 布局跳动：字体改为 `display=optional` + preconnect（零换排）；
  `scrollbar-gutter: stable` 消除滚动条出现/消失的横向跳动；
  `pageswap` 时回顶对齐，消除过渡中的上下跳动；
  移除前台 twemoji 脚本；admin-bar 吸顶偏移修正；Hero 图 preload；兜底图补宽高。
- 白屏：`<head>` 内联脚本在 CSS 到达前先铺纸色底（明暗两套），文档初始绘制不再是浏览器白底。

### 调整
- 首页右栏标签区从胶囊容器改为「小节标题 + 纯文字标签流」，多标签自然换行。
- 导航/分享的复制链接改为事件委托，适配 PJAX 局部替换。
